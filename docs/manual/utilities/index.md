# Utilities and Export

Getting work out of Crystal Builder: the file formats it reads and
writes and what each one keeps, the *Export…* door that cleans a
structure for another program, a picture of the view at the size a
journal asks for, and one unit cell as a mesh a 3D printer can take.
After this chapter you can choose the right format for the program
that comes next, say what will be lost before it is, make a figure
that matches what you see on screen, and hand a framework to Blender
for printing.

The *File* menu's commands are described one by one in
{doc}`the Essentials chapter </essentials/file>`; this chapter goes
deeper on the formats themselves and on what an export contains.  The
settings every dialog offers are listed in the {ref}`generated
reference <reference-appendix>`, which the application writes itself,
and are linked rather than retyped.
