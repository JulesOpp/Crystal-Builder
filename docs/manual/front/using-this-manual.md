# How to use this manual

The manual starts with a {doc}`quickstart </quickstart/index>` that
installs Crystal Builder and walks through a first build.  The
{doc}`essential elements </essentials/index>` follow, one section per
menu.  The chapters after that are organised by what you are trying to
do -- compute an energy, find a structure, measure a pore, build a
framework, run things from a script -- and the appendices hold the
reference.

A section on a method starts with a short outline of the theory and
its references, gives practical advice, works an example on one of
the sample structures, and ends with the method's settings and its
limitations.

## The reference is generated

Every command, module setting, engine option and panel is listed in
the {ref}`reference appendix <reference-appendix>`, which is written
by the application itself and not by hand.  It cannot fall out of
step with the version it was built from, which is why the chapters
link to it for the full list of options rather than repeating it.

## Conventions

- Menu commands are written as the menu shows them, with ▸ between
  levels: *File ▸ Open Sample ▸ MOF-5*.
- Keys are written as they are pressed: {kbd}`Ctrl+S`.  On macOS,
  {kbd}`Ctrl` is {kbd}`⌘`.
- `Monospace` is something you type: a command, a file name, a
  setting's value.
- Units are those the application shows: Å, kcal/mol, kcal/mol/Å,
  GPa.
