# Essential Elements

One section per menu, in the order the menu bar shows them -- *File,
Edit, Select, Structure, Symmetry, Cell, Measure, View, Modules,
Window* and *Help* -- followed by the mouse modes and a table of every
keyboard shortcut.  After this chapter you know what each command is
for, when to reach for it, and the behaviour that follows from how
Crystal Builder keeps a structure: bonds that change only when you
ask, sites that sit on special positions, a save that turns a CIF into
a project.

Every command is named here as the menu shows it and linked to its
entry in the {doc}`command reference </reference/commands>`, which the
application writes itself; this chapter says what a command is for and
when you would choose it, and the reference lists what it takes.  The
calculations -- the *Modules* menu -- are taken by task in the chapters
that follow, so their page here is short.
