# Essential Elements

One section per menu, in the order the menu bar shows them: what each command is for, when to reach for it, and the behaviour that follows from how Crystal Builder stores a structure -- bonds that change only when you ask, sites that sit on special positions, a save that converts a CIF into a project.

:::{note}
This chapter is being written.  Until it is, the generated reference
in {ref}`the appendix <reference-appendix>` describes every command,
module and setting the application offers.
:::

## What this chapter will cover

- Files, workspaces and samples
- Editing and the undo stack
- Selection
- Structure: atoms, bonds and connection points
- Symmetry: space groups, Wyckoff positions, subgroups
- The cell: supercells, reductions and transformations
- Measurements and planes
- Viewing and styles
- Mouse modes and keyboard shortcuts
