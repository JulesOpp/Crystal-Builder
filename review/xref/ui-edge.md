## Fell through the cracks, ranked

1. **Find symmetry's default button is still *Close*, not *Adopt* — ui-ux finding 6.** The single most deceptive miss: the source already contains `self.adopt_button.setDefault(True)`, so anyone re-reading the diff would conclude it was fixed. It wasn't — the call happens before the button joins the `QDialogButtonBox`, so it never takes effect, and this was true *before* the review too (the line dates to commit `4f28eb4`, well before `3cd15e2`). No test covers it. Pressing Return after reading a correct space-group in the dialog still closes it without adopting anything. **Confirmed by direct headless reproduction**, not just static reading.
2. **The toolbar overflow (ui-ux finding 10) got slightly worse, not better.** The toolbar's `sizeHint()` grew from 1342 pt to 1356 pt across the five PRs (new engine/menu entries), while the default-window-size formula is untouched — so on the same screen size the review measured, the chevron overflow the review documented is still there, and by a slightly larger margin. Nothing tracks it.
3. **Two energy-adjacent things a MOF/framework user will ask for are simply absent**: energy units as a preference (kcal/mol · kJ/mol · eV) and the VESTA/Avogadro-style selection tools (radius, Wyckoff letter, saved selections). Both were explicit "ten improvements" recommendations, neither logged anywhere.
4. **`.gen` still cannot round-trip the empty structure File ▸ New makes** — a new document that gets no atoms added and is exported to `.gen` produces a file nothing can read back, with no warning at export time. Same failure, verified reproducing byte-for-byte.
5. **A read-only workspace still turns a module run into a bare Python traceback** (`process.py:366`'s unguarded `mkdir`) rather than the polite "could not create the run folder" sentence the rest of that file works hard to give everywhere else.
6. **`safe_name`'s non-ASCII handling is unchanged**: `café` and `cafè` still both become the folder name `caf`. Content de-duplication papers over it for now, but the entry names stay misleading, exactly as the review said.
7. **Screen-reader support (ui-ux finding 12) and the three panel-sizing polish items (7, 8, 9) are honestly deferred** — quoted almost verbatim into `docs/TODO.md` § Interface — so these are the *good* kind of "not done": tracked, acknowledged, and attributed to the same review.

Everything else in both reports' numbered findings (11 of 14 in ui-ux; all 13 numbered + one of eight "smaller things" in edge-cases) shipped, mostly in PR #6's six-phase shell track and PR #2's twelve correctness fixes, and was verified either by reading the current source at the cited file:line or by a live headless repro against `main`.
